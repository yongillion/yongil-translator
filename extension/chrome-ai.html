On-Device AI

Use the browser’s built-in model without an API key. Keep the model tab open while translating. Setup may download a model. The browser determines where processing takes place.

Language support depends on your browser’s model. Choose a supported target language; unsupported source languages cannot be translated.

Settings

Processes one block at a time. Closing this tab stops translation. This extension does not send these prompts to its cloud API providers; the browser controls model execution.
