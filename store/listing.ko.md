# 한국어 스토어 소개

## 이름

Yongil Translator

## 짧은 설명

ChatGPT 구독으로 웹페이지, 블록, 선택한 텍스트를 번역하세요. 필요할 때 언제든 원문으로 복원할 수 있습니다.

## 상세 설명

Yongil Translator로 웹페이지를 원하는 언어로 읽어보세요. 연결한 ChatGPT 구독 계정을 사용해 페이지 전체, 개별 블록, 드래그한 텍스트를 번역할 수 있습니다.

사용 가능한 모델 권한이 있는 호환 ChatGPT 구독 계정이 필요합니다. 번역은 연결한 계정의 사용량을 소모하며 해당 계정의 한도가 적용됩니다. 확장 프로그램은 무료 오픈소스이며 ChatGPT 구독을 포함하지 않습니다. 현재 버전은 API 키나 별도의 연결 프로그램 설치를 요구하지 않습니다.

원하는 범위만 번역

- 읽을 수 있는 페이지 텍스트를 기존 구조를 유지하며 번역합니다.
- Alt를 누르고 블록을 클릭하면 번역됩니다. 번역된 블록을 같은 방법으로 클릭하면 원문으로 복원됩니다.
- 블록 선택 모드에서는 여러 블록을 연속해서 번역하거나 복원할 수 있습니다.
- 텍스트를 드래그한 뒤 번역 버튼을 누르면 결과 팝업이 나타납니다. 팝업은 이동, 크기 조절, 닫기가 가능합니다.
- 번역한 페이지를 언제든 원문으로 복원할 수 있습니다.

나에게 맞는 번역 설정

- 편집 가능한 언어 목록에서 선택하거나 원하는 언어를 직접 입력하세요.
- 언어와 지역 이름을 해당 언어 및 현재 UI 언어로 확인하세요.
- 계정에서 사용할 수 있는 모델을 선택하세요.
- 커스텀 인스트럭션으로 번역의 어조와 스타일을 지정하세요.
- 동시 번역 요청 수를 1~64개로 설정하세요. 기본값은 16개이며 모든 탭이 같은 한도를 공유합니다.
- 영어와 한국어 UI를 지원합니다. 브라우저 언어를 따르거나 설정에서 직접 선택할 수 있습니다.

기본 단축키

- Alt+T: 페이지 번역
- Alt+R: 진행 중인 번역을 중단하고 페이지 원문 복원
- Alt+클릭: 블록 번역 또는 원문 복원
- Escape: 블록 선택 모드 종료

단축키는 변경할 수 있으며 웹페이지에 포커스가 있을 때 동작합니다. 브라우저나 운영체제에 예약된 단축키가 우선할 수 있습니다.

사이트 접근과 개인정보

현재 사이트만 또는 모든 HTTP/HTTPS 사이트에 대한 접근을 선택할 수 있습니다. 사이트 접근을 허용하고 번역 동작을 실행해야 텍스트가 번역됩니다. 텍스트 선택만으로는 전송되지 않습니다.

번역할 텍스트와 활성화된 커스텀 인스트럭션은 OpenAI에 직접 전송됩니다. 인증 정보와 설정은 확장 프로그램의 로컬 저장소에 보관됩니다. 원문과 번역 결과는 현재 문서의 메모리에만 캐싱되며 새로고침하면 삭제됩니다. 개발자가 운영하는 중계 서버, 광고, 분석 도구는 없습니다.
