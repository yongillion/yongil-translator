# 한국어 스토어 소개

## 이름

Yongil Translator

## 짧은 설명

ChatGPT 구독, OpenAI API 키 또는 Claude API 키로 웹페이지, 블록, 선택한 텍스트를 번역하세요. 필요할 때 언제든 원문으로 복원할 수 있습니다.

## 상세 설명

Yongil Translator로 웹페이지를 원하는 언어로 읽어보세요. 연결한 ChatGPT 구독 계정, OpenAI API 키 또는 Claude API 키를 사용해 페이지 전체, 개별 블록, 드래그한 텍스트를 번역할 수 있습니다.

사용 가능한 모델 권한과 한도가 있는 ChatGPT 구독 계정, OpenAI API 키 또는 Claude API 키를 선택할 수 있습니다. 구독 방식은 계정의 구독 사용량을 소모하며, API 방식은 선택한 제공업체(OpenAI 또는 Anthropic)에서 별도로 과금됩니다. Claude는 API 키만 지원하며 구독으로 사용할 수 없습니다. 연결 카드에서 방식을 전환할 수 있고, 자동으로 다른 과금 방식으로 전환하지 않습니다. 확장 프로그램은 무료 오픈소스이며 구독이나 API 크레딧을 포함하지 않습니다. 별도 연결 프로그램 설치는 필요하지 않습니다.

원하는 범위만 번역

- 읽을 수 있는 페이지 텍스트를 기존 구조를 유지하며 번역합니다.
- Alt를 누르고 블록을 클릭하면 번역됩니다. 번역된 블록을 같은 방법으로 클릭하면 원문으로 복원됩니다.
- 블록 선택 모드에서는 여러 블록을 연속해서 번역하거나 복원할 수 있습니다.
- 텍스트를 드래그한 뒤 번역 버튼을 누르면 결과 팝업이 나타납니다. 팝업은 이동, 크기 조절, 닫기가 가능합니다.
- 번역한 페이지를 언제든 원문으로 복원할 수 있습니다.

나에게 맞는 번역 설정

- 편집 가능한 언어 목록에서 선택하거나 원하는 언어를 직접 입력하세요.
- 언어와 지역 이름을 해당 언어 및 현재 UI 언어로 확인하세요.
- 계정에서 사용할 수 있는 모델을 선택하세요.
- 커스텀 인스트럭션으로 번역의 어조와 스타일을 지정하세요.
- 동시 번역 요청 수를 1~64개로 설정하세요. 기본값은 16개이며 모든 탭이 같은 한도를 공유합니다.
- 영어와 한국어 UI를 지원합니다. 브라우저 언어를 따르거나 설정에서 직접 선택할 수 있습니다.

기본 단축키

- Alt+T: 페이지 번역
- Alt+R: 진행 중인 번역을 중단하고 페이지 원문 복원
- Alt+클릭: 블록 번역 또는 원문 복원
- Escape: 블록 선택 모드 종료

단축키는 변경할 수 있으며 웹페이지에 포커스가 있을 때 동작합니다. 브라우저나 운영체제에 예약된 단축키가 우선할 수 있습니다.

사이트 접근과 개인정보

현재 사이트만 또는 모든 HTTP/HTTPS 사이트에 대한 접근을 선택할 수 있습니다. 사이트 접근을 허용하고 번역 동작을 실행해야 텍스트가 번역됩니다. 텍스트 선택만으로는 전송되지 않습니다.

번역할 텍스트와 활성화된 커스텀 인스트럭션은 선택한 제공업체(OpenAI 또는 Anthropic)에 직접 전송됩니다. 오류 발생 시 자동 재시도는 0-10회로 설정할 수 있으며 기본 4회이고 추가 사용량이 발생할 수 있습니다. 인증 정보와 설정은 확장 프로그램의 로컬 저장소에 보관됩니다. 원문과 번역 결과의 캐시는 현재 문서의 메모리에 유지되며 새로고침하면 삭제됩니다. 선택 기능인 개발자 모드를 켜면 요청·응답·오류 로그도 로컬에 별도로 저장되며 사이드패널에서 과거 기록과 실시간 출력을 확인할 수 있습니다. 로그는 설정·인증 정보와 공유하는 기본 로컬 저장소의 남은 공간 내에서 최대 로그 개수(기본 4,000개, 1-1,000,000개 설정 가능)까지 최근 항목을 보관하고, 로그 삭제로 지울 수 있습니다. 인증 토큰은 로그에서 제외됩니다. 개발자가 운영하는 중계 서버, 광고, 분석 도구는 없습니다.

지원 범위

Chrome 내부 페이지, 확장 프로그램 스토어, 브라우저 내장 PDF 뷰어, 이미지 속 텍스트는 지원하지 않습니다. 모델 및 서비스 이용 가능 여부, 번역 품질은 연결한 계정과 제공 서비스에 따라 달라집니다. 무제한 사용이나 특정 배수의 속도 향상을 보장하지 않습니다.

Yongil Translator는 독립 프로젝트이며 OpenAI, Anthropic, Google, GitHub가 제작하거나 보증하는 제품이 아닙니다.

## 온디바이스 AI (실험적 기능)

브라우저 내장 Prompt API의 사용 가능 여부를 확인해 선택지를 표시합니다. Chrome으로 제한하지 않으며 삼성·Edge 등도 호환 API와 모델이 있으면 사용할 수 있습니다. 미지원 기기나 정책으로 차단된 경우에는 표시하지 않습니다. 대상 언어도 API로 확인하며 한국어를 지원하는 모델에서는 한국어도 선택할 수 있습니다.

모델 탭에서 준비 버튼을 눌러 필요한 모델을 다운로드하세요. 백그라운드 실행 준비가 확인되면 탭을 닫아도 번역할 수 있습니다. 이를 지원하지 않는 브라우저에는 탭을 열어 두라는 안내를 표시합니다. 한 번에 한 블록씩 처리하며 원문 복원, 캐시, 오류 재시도, 개발자 로그를 지원합니다. 확장 프로그램이 OpenAI·Anthropic API로 자동 전환하지 않습니다. 다만 API 사용 가능 상태만으로 기기 내 실행을 보장할 수 없으며 모델 실행 위치와 다운로드는 브라우저 구현 및 정책에 따릅니다. 각 브라우저의 실제 동작은 추가 검증이 필요합니다.

## Translator API

지원 브라우저에서는 별도의 Translator API 방식을 선택할 수 있습니다. 계정이나 API 키 없이 브라우저 번역 엔진을 사용합니다. 번역 탭에서 Source·Target 언어를 선택하고 언어 팩을 준비하세요. 백그라운드 실행 준비가 확인되면 탭을 닫고도 페이지·블록·선택 텍스트를 번역할 수 있습니다. 새로운 언어 쌍은 추가 준비가 필요할 수 있습니다. 원본 언어는 자동으로 인식하며 원문 복원과 페이지 캐시를 지원합니다. 사용자 지시문은 적용되지 않습니다.

브라우저 이름 대신 API와 지원 언어 쌍을 검사합니다. 다운로드와 처리 위치는 브라우저가 관리하며 클라우드 제공자로 자동 전환하지 않습니다. 실제 브라우저별 모델 검증은 아직 완료되지 않았습니다.
