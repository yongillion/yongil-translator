테스트는 로컬 JavaScript 실행 환경에서 수행했습니다. 브라우저 DOM을 사용하는 실제 확장 E2E 테스트와 제공자 실계정 테스트를 대체하지 않습니다. 통합 테스트의 계정·토큰·모델·추론 응답은 테스트용 모의 값이며 실제 사용자 정보가 아닙니다.

주요 검증 내용:

- PKCE 표준 벡터, 콜백의 정확한 주소·state, 서명·issuer·audience·만료·nonce

- 콘텐츠 스크립트의 계정 관리 접근 차단, 토큰 비공개
- 문서 간 작업 ID 재사용 거부, 작업 시작 시 설정 고정
- 로그아웃·제외 사이트·명시적 원문 복원의 요청 처리

## 브라우저 검증 절차

1. `extension/`을 Chrome 개발자 모드에서 로드합니다.
2. 팝업에서 계정 로그인을 실행하고 기존 세션의 계정이 사용되는지 확인합니다. 비밀번호나 토큰을 로그·문서에 복사하지 않습니다.
3. 실제 모델 목록을 조회하고 모델을 선택합니다. 짧은 공개 텍스트로 실제 번역을 확인합니다.
4. `node scripts/serve-fixture.mjs`를 실행한 뒤 `http://localhost:3185/fixture.html`을 엽니다. 이 서버는 개발용 fixture 전용이며 확장의 설치·인증·일반 사용에 필요하지 않습니다.
5. 페이지 번역 → 블록 하나 복원 → 전체 원문 복원을 확인합니다. 링크 클릭 횟수와 강조·표 구조가 보존되어야 합니다.
6. 개별 블록 두 개를 번역한 후 페이지 원문 복원으로 두 블록을 모두 복원합니다.
7. 페이지 번역 도중 원문 복원을 누르고, 이후 늦게 도착한 응답이 텍스트를 바꾸지 않는지 확인합니다.
8. 번역된 문단에서 사이트 텍스트 변경 버튼을 누른 후 원문 복원을 실행합니다. 사이트의 새로운 텍스트는 유지되어야 합니다.
9. 폼·편집기·코드·숨겨진 요소가 번역되지 않는지 확인합니다.
10. Alt+Shift+T, Alt+Shift 유지·클릭, 설정한 대체 단축키와 선택 취소를 확인합니다.
11. 새로고침, SPA 이동, 프레임, 열린 Shadow DOM, 로그인 해제, 오프라인 복원을 확인합니다.
12. 팝업과 설정 화면을 밝게·어둡게, 100·125·150·200% 배율로 검토합니다.
13. 동등한 조건으로 Edge·Brave를 검증하고 실제 지원 결과를 기록합니다.

실제 확장 환경에서 언어 팩 다운로드와 브라우저 번역은 검증하지 못했습니다. 출시 전 사용할 브라우저별로 실제 API 노출, 두 번째 언어 쌍 준비, 페이지·블록·선택 번역, 원문 복원·캐시, 취소·탭 닫기, 미지원 언어·정책 차단, 제공자 전환을 확인해야 합니다. 전체 검증 항목은 루트 TESTING.md를 참고하세요.
