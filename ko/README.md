# Yongil Translator

ChatGPT 구독 계정, OpenAI API 키 또는 Claude API 키로 웹페이지를 제자리에서 번역하는 Chromium 확장입니다. 페이지 전체와 선택한 블록을 번역하고, 언제든 원문으로 되돌릴 수 있습니다.

**현재 상태:** 첫 구현과 자동 회귀 테스트를 완료했습니다. 실제 Chrome 설치, 로그인된 계정을 통한 OAuth·모델 조회·번역, Edge·Brave 호환성은 아직 검증하지 못했습니다. 구독 연결을 검증 완료된 기능으로 보장하는 배포판은 아닙니다.

## 설치

1. 이 저장소를 내려받습니다. 별도 빌드나 npm 설치는 필요하지 않습니다.
2. Chrome의 `chrome://extensions`에서 개발자 모드를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**에서 저장소의 **extension** 폴더를 선택합니다.
4. 확장 팝업에서 **ChatGPT 구독**으로 로그인하거나 **OpenAI API** 또는 **Claude API**를 선택해 해당 키를 입력하고 연결합니다. API 사용량은 선택한 제공업체(OpenAI 또는 Anthropic)에서 별도로 과금됩니다. Claude는 API 키만 지원하며 구독·OAuth 연결은 지원하지 않습니다.
5. 실제 계정에서 조회된 모델을 선택한 뒤 번역할 언어를 지정합니다.
6. 웹페이지에서 **페이지 번역**을 실행합니다. 블록 선택 키를 바로 쓰려면 해당 사이트 접근을 허용하세요. 이미 열려 있던 탭은 새로고침하거나 팝업의 블록 선택 버튼으로 활성화합니다.

Chrome 내장 페이지, 확장 스토어, 브라우저 PDF 뷰어와 이미지 안의 글자는 번역 대상이 아닙니다. 일부 사이트는 브라우저 자체의 스크립트 주입 제한을 적용합니다.

## 사용

| 동작 | 방법 |
|---|---|
| 페이지 번역 | Alt+Shift+T 또는 팝업의 페이지 번역 |
| 블록 번역 | Alt+Shift를 누른 채 블록을 가리키고 클릭 |
| 블록 원문 복원 | 번역된 블록을 같은 방법으로 클릭하거나 블록 도구막대 사용 |
| 페이지 원문 복원 | 팝업 또는 페이지 도구막대의 원문 복원 |
| 선택 모드 종료 | Escape. 설정에서 변경·해제 가능 |
| 페이지 명령키 변경 | 설정 → 단축키 → 브라우저 단축키 설정 |
| 블록 선택·취소 키 변경 | 설정 → 단축키에서 키 기록 |

- 언어 입력란에는 목록 선택과 직접 입력을 모두 사용할 수 있습니다.
- 최초 언어는 **브라우저 UI 언어** 기준입니다. 확장에서 운영체제 언어를 정확히 읽는 방법은 확보하지 못했으므로 OS 언어로 표시하지 않습니다.
- 소스 언어는 내부에서 자동 인식하며 별도의 UI 행은 없습니다.
- 커스텀 인스트럭션은 명시적으로 저장하고, 이후 시작하는 번역부터 적용합니다.
- 페이지 원문 복원에는 개별적으로 번역한 블록도 포함됩니다.
- 번역 중지와 원문 복원은 별개입니다. 중지는 이미 적용된 번역을 유지합니다.
- 복원 후 늦게 도착한 응답은 적용하지 않습니다. 사이트가 수정한 텍스트는 오래된 원문으로 덮어쓰지 않습니다.
- 폼·편집기·비밀번호·숨겨진 요소·코드 블록은 수집하지 않습니다. 한 텍스트 노드가 16,000자를 넘거나 탐색 한도를 넘으면 제외 사실을 표시합니다.
- 접근 권한이 있는 프레임과 열린 Shadow DOM은 처리 대상으로 삼습니다. 닫힌 Shadow DOM과 접근 불가 프레임은 지원하지 않습니다.

## 인증과 데이터

연결 카드에서 ChatGPT 구독, OpenAI API, Claude API를 전환할 수 있습니다. 각 방식의 연결 정보와 모델 선택은 따로 유지됩니다. 전환 시 진행 중인 번역은 중단되며, 연결 해제는 현재 선택한 방식의 인증정보만 삭제합니다. API 키는 이 브라우저의 trusted-context 로컬 저장소에만 보관하고 설정 내보내기와 개발자 로그에서 제외합니다. 저장된 키는 입력란에 다시 표시하지 않습니다. API 키 변경 버튼으로 교체할 수 있으며 API 모드에서는 계정 이메일을 요청하지 않습니다. 현재 전체 사용법과 검증 상태는 [영문 README](../README.md)와 [TESTING](../TESTING.md)을 기준으로 확인하세요.

확장 내부에서 OAuth Authorization Code + PKCE를 처리합니다. 로그인 전용 탭이 지정된 콜백 URL로 이동할 때 코드를 확인하므로 로컬 서버나 연결 프로그램을 설치하지 않습니다. 공개 Codex 클라이언트와 호환되는 경로를 사용하며, 일반 외부 앱용 공식 구독 연결과 동일한 지원을 보장하지 않습니다. 실제 계정에서의 동작은 별도 검증 대상입니다.

인증정보는 콘텐츠 스크립트에 공개하지 않습니다. 토큰은 trusted context로 접근을 제한한 확장 저장소에 보관합니다. 원문·번역문·복원 스냅샷은 현재 페이지 메모리에만 둡니다. 설정 내보내기는 인증정보를 제외한 허용 필드만 포함합니다. 상세 사항은 [개인정보 처리 설명](PRIVACY.md)을 참고하세요.

## 개발과 검증

런타임 의존성 없는 JavaScript ES modules와 표준 DOM API를 사용합니다. 처음 제안했던 TypeScript·Vite·React 구성 대신 압축해제 설치가 바로 가능한 구조로 구현했습니다. Node.js 20 이상은 개발 검증·패키징에만 필요합니다.

```sh
npm test
npm run check
npm run package
```

테스트는 실제 계정 요청 없이 OAuth 검증, 출력 구조·스트림, 원문 복원, 취소 경쟁 조건, 서비스 워커의 메시지 경계와 계정 상태를 확인합니다. 실제 브라우저 검증 절차와 실행 결과는 [TESTING.md](TESTING.md)에 있습니다.

- `extension/`: 바로 설치할 확장
- `extension/lib/`: 설정, OAuth, 구독 요청, 응답 검증
- `extension/document-core.js`: 원문 스냅샷과 세대 관리
- `extension/content.js`: DOM 수집, 번역·복원, 페이지 위 UI
- `extension/background.mjs`: 인증 이벤트, 작업 큐, 권한·메시지 처리
- `tests/`: 회귀·통합 테스트와 브라우저용 fixture
- `scripts/`: 구문 검사, 아이콘 렌더링, ZIP 패키징

대표 심볼과 기능 아이콘은 이 프로젝트용으로 작성했습니다. 코드와 포함된 디자인 자산은 [MIT 라이선스](LICENSE)를 적용합니다.

## 온디바이스 AI (실험적 기능)

브라우저 이름 대신 확장 문서에서 LanguageModel.availability()와 create()를 제공하는지 확인합니다. 사용 가능·다운로드 가능·다운로드 중 상태이며 지원되는 대상 언어가 있을 때만 선택지가 나타납니다. API가 없거나 기기·정책 제한, 확인 오류가 있으면 Chrome에서도 숨깁니다. 삼성·Edge 등도 호환 API가 있으면 사용할 수 있으며, 해당 브라우저의 실제 모델 동작은 아직 검증하지 않았습니다.

**온디바이스 AI**를 선택하고 모델 탭을 연 뒤 **로컬 모델 준비**를 누르세요. 지원 확인만으로 다운로드를 시작하지 않습니다. 번역 중에는 모델 탭을 열어 두어야 하며 추가 언어 다운로드가 필요하면 다시 준비 버튼을 누릅니다. 대상 언어는 API에 조회하며 브라우저가 지원하면 한국어도 표시됩니다. 기존 번역 언어 설정은 유지합니다. 요청마다 감지된 원문 언어와 대상 언어를 포함한 동일한 옵션으로 사용 가능 여부와 세션 생성을 확인합니다.

한 번에 한 블록씩 처리하며 오류 재시도, 원문 복원, 페이지 캐시, 개발자 로그를 지원합니다. 확장 프로그램이 OpenAI·Anthropic으로 자동 전환하지 않습니다. 다만 Prompt API의 사용 가능 상태만으로 기기 내 실행을 보장할 수는 없습니다. 모델 실행 위치와 다운로드는 브라우저 구현 및 정책에 따릅니다. 각 브라우저의 실제 다운로드와 추론 검증이 필요합니다.

## Translator API

Prompt API 기반 온디바이스 AI와 별개의 브라우저 번역 방식입니다. 계정이나 API 키가 필요하지 않습니다. 브라우저 이름이 아니라 확장 화면의 `Translator.availability()`·`Translator.create()`와 지원 언어 쌍을 확인하여 선택지를 표시합니다. 미지원 환경에서는 숨깁니다.

1. **Translator API → 브라우저 번역 탭 열기**를 선택합니다.
2. 표시된 언어 쌍의 **언어 팩 준비**를 누르고 탭을 열어 둡니다.
3. 사이트 접근을 허용하고 대상 언어를 선택한 뒤 기존 페이지·블록·선택 텍스트 번역을 사용합니다.
4. 새로운 언어 쌍의 다운로드가 필요하면 번역 탭에서 해당 팩을 준비한 뒤 실패한 블록을 다시 번역합니다.

원본 언어는 블록 전체를 분석해 자동 판단합니다. 짧거나 모호한 텍스트는 페이지에 선언된 언어를 참고하며, 잘못 판단할 수도 있습니다. 실제 요청마다 언어 쌍의 지원 여부를 검사합니다. 번체·간체는 구분합니다. 한 번에 한 블록씩 처리하고, 인라인 요소 보존을 위해 텍스트 노드별로 번역하므로 노드 사이의 문맥 품질은 LLM과 다를 수 있습니다. 원문 복원·페이지 캐시·설정된 오류 재시도·개발자 로그가 적용됩니다. 사용자 지시문은 숨기고 적용하지 않으며 다른 제공자용 설정은 보존합니다.

탭을 닫으면 번역이 중단됩니다. 클라우드 제공자로 자동 전환하지 않습니다. 다운로드와 처리 위치는 브라우저가 결정하며 추가 권한은 요청하지 않습니다. 실제 브라우저 언어 팩 다운로드와 번역은 이 개발 환경에서 검증하지 못했습니다.
