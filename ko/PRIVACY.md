# 개인정보 처리 설명

Yongil Translator는 개발자 서버로 페이지 내용이나 계정 정보를 수집하지 않습니다.

사용자가 번역을 실행하면 선택한 페이지·블록의 텍스트, 타겟 언어, 선택한 모델, 활성화한 커스텀 인스트럭션을 선택한 OpenAI 구독 서비스 또는 공개 API에 직접 전송합니다. API 사용량은 OpenAI에서 별도로 과금됩니다. 입력 폼, 비밀번호, 편집 중인 내용, 숨겨진 요소는 수집 대상에서 제외합니다. 원본 URL의 쿼리나 프래그먼트를 번역 요청에 붙이지 않습니다.

OAuth 로그인에는 OpenAI 로그인 페이지를 사용합니다. 확장은 사용자의 암호를 읽거나 저장하지 않습니다. 로그인 전용 탭에서 인증 코드를 받은 뒤 PKCE로 교환하며, ID 토큰의 서명·발급자·대상·만료·nonce를 검증합니다. 다른 탭의 로그인 코드나 탐색 기록을 수집하지 않습니다.

로그인 유지에 필요한 토큰과 사용자가 입력한 API 키는 해당 브라우저의 확장 local 저장소에 보관합니다. 이 저장소는 콘텐츠 스크립트 접근을 제한하지만 OS 자격 증명 보관소와 같은 암호화 저장소는 아닙니다. API 키는 api.openai.com의 인증 헤더로만 전송하며 구독 백엔드나 개발자 서버에는 전송하지 않습니다. API 모드는 이메일 주소를 요청하지 않습니다. 연결 해제는 현재 선택한 방식의 인증정보와 모델 캐시를 삭제합니다. 방식 전환 시 다른 방식의 인증정보는 유지되므로 모두 삭제하려면 각 방식에서 연결을 해제하세요. 제공자 서버의 승인 취소나 API 키 폐기는 제공자 설정에서 별도로 관리할 수 있습니다.

사용자 설정은 브라우저 local 저장소에 보관하고, 원문·번역문·원문 복원용 노드 참조는 문서의 메모리에만 보관합니다. 페이지를 이동하거나 닫으면 해당 문서의 메모리도 해제됩니다. 임시 번역 캐시를 지워도 현재 문서의 원문 복원용 스냅샷은 유지합니다.

원문 복원은 새 번역 요청 없이 수행합니다. 자동 재시도는 기본 최대 4회이며 구독 사용량 또는 API 비용이 추가될 수 있습니다. 중지·복원은 이미 OpenAI에 전달된 요청의 사용량이 취소되거나 환불된다는 의미는 아닙니다. 요청의 store=false는 OpenAI 측 데이터 처리·보관 정책을 대체하지 않습니다.

## 선택적 개발자 로그

개발자 모드는 기본적으로 꺼져 있습니다. 켜면 요청한 원문·지침, 응답과 스트림 이벤트, 오류, 재시도를 이 브라우저에 기록합니다. 인증 헤더, 토큰 교환 및 API 키 확인 요청의 인증정보는 기록하지 않습니다. 인식된 인증 필드와 API 키 문자열은 가리고, 키를 포함할 수 있는 API HTTP 오류 본문은 저장하지 않습니다. 로그에는 개인정보가 포함된 페이지 내용이 남을 수 있습니다.

최대 로그 개수는 기본 4,000개이며 1~1,000,000개로 설정할 수 있습니다. 브라우저 기본 local 저장소의 남은 한도와 개수 제한 안에서 저장하며 오래된 항목부터 삭제합니다. 브라우저 재시작·페이지 새로고침·연결 해제 후에도 유지됩니다. 개발자 모드를 끄면 새 기록은 중단되지만 기존 기록은 남습니다. 로그 삭제 버튼이나 확장 제거로 삭제할 수 있습니다. 설정 내보내기는 인증정보와 로그를 포함하지 않습니다.

## 권한

- storage: 설정, 인증 상태, API 키, 일시적인 로그인 상태, 선택적 개발자 로그
- scripting: 접근을 허용한 웹페이지에 번역 기능 주입
- tabs: 로그인 전용 탭과 현재 대상 탭 확인
- alarms: 로그인 시간 초과 및 콜백 누락 확인
- webNavigation: 접근 가능한 프레임 열거, 문서 이동에 따른 요청 무효화, 지정된 로그인 콜백 감지
- auth.openai.com·chatgpt.com: 인증·모델 조회·구독 번역
- api.openai.com: API 키 검증·모델 조회·API 번역
- sidePanel: 개발자 로그를 브라우저 사이드 패널에 표시
- 선택한 웹사이트 접근: 해당 사이트에서 번역과 단축키 사용

분석 SDK, 광고, 원격 실행 코드, 개발자 운영 프록시는 포함하지 않습니다.
