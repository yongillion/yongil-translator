# 개인정보 처리 설명

Yongil Translator는 개발자 서버로 페이지 내용이나 계정 정보를 수집하지 않습니다.

사용자가 번역을 실행하면 선택한 페이지·블록의 텍스트, 원본 언어 선택, 타겟 언어, 선택한 모델, 활성화한 커스텀 인스트럭션을 선택한 OpenAI 구독 서비스, OpenAI API 또는 Anthropic의 Claude API에 직접 전송합니다. API 사용량은 선택한 제공업체에서 별도로 과금됩니다. Claude는 API 키만 지원하며 구독·OAuth 연결은 사용하지 않습니다. 입력 폼, 비밀번호, 편집 중인 내용, 숨겨진 요소는 수집 대상에서 제외합니다. 원본 URL의 쿼리나 프래그먼트를 번역 요청에 붙이지 않습니다.

OAuth 로그인에는 OpenAI 로그인 페이지를 사용합니다. 확장은 사용자의 암호를 읽거나 저장하지 않습니다. 로그인 전용 탭에서 인증 코드를 받은 뒤 PKCE로 교환하며, ID 토큰의 서명·발급자·대상·만료·nonce를 검증합니다. 다른 탭의 로그인 코드나 탐색 기록을 수집하지 않습니다.

로그인 유지에 필요한 토큰과 사용자가 입력한 API 키는 해당 브라우저의 확장 local 저장소에 보관합니다. 이 저장소는 콘텐츠 스크립트 접근을 제한하지만 OS 자격 증명 보관소와 같은 암호화 저장소는 아닙니다. OpenAI 키는 api.openai.com으로, Claude 키는 api.anthropic.com으로 해당 API의 인증 헤더로만 전송하며 구독 백엔드나 개발자 서버에는 전송하지 않습니다. API 모드는 이메일 주소를 요청하지 않습니다. 연결 해제는 현재 선택한 방식의 인증정보와 모델 캐시를 삭제합니다. 방식 전환 시 다른 방식의 인증정보는 유지되므로 모두 삭제하려면 각 방식에서 연결을 해제하세요. 제공자 서버의 승인 취소나 API 키 폐기는 제공자 설정에서 별도로 관리할 수 있습니다.

사용자 설정은 브라우저 local 저장소에 보관하고, 원문·번역문·원문 복원용 노드 참조는 문서의 메모리에만 보관합니다. 페이지를 이동하거나 닫으면 해당 문서의 메모리도 해제됩니다. 임시 번역 캐시를 지워도 현재 문서의 원문 복원용 스냅샷은 유지합니다.

원문 복원은 새 번역 요청 없이 수행합니다. 자동 재시도는 기본 최대 4회이며 구독 사용량 또는 API 비용이 추가될 수 있습니다. 중지·복원은 이미 선택한 제공업체에 전달된 요청의 사용량이 취소되거나 환불된다는 의미는 아닙니다. OpenAI 요청의 store=false는 제공업체의 데이터 처리·보관 정책을 대체하지 않습니다. Claude 요청에는 이 OpenAI 전용 필드를 보내지 않습니다.

## 선택적 개발자 로그

개발자 모드는 기본적으로 꺼져 있습니다. 켜면 요청한 원문·지침, 응답과 스트림 이벤트, 오류, 재시도를 이 브라우저에 기록합니다. 인증 헤더, 토큰 교환 및 API 키 확인 요청의 인증정보는 기록하지 않습니다. 인식된 인증 필드와 API 키 문자열은 가리고, 키를 포함할 수 있는 API HTTP 오류 본문은 저장하지 않습니다. 로그에는 개인정보가 포함된 페이지 내용이 남을 수 있습니다.

최대 로그 개수는 기본 4,000개이며 1~1,000,000개로 설정할 수 있습니다. 브라우저 기본 local 저장소의 남은 한도와 개수 제한 안에서 저장하며 오래된 항목부터 삭제합니다. 브라우저 재시작·페이지 새로고침·연결 해제 후에도 유지됩니다. 개발자 모드를 끄면 새 기록은 중단되지만 기존 기록은 남습니다. 로그 삭제 버튼이나 확장 제거로 삭제할 수 있습니다. 설정 내보내기는 인증정보와 로그를 포함하지 않습니다.

## 권한

- storage: 설정, 인증 상태, API 키, 일시적인 로그인 상태, 선택적 개발자 로그
- scripting: 접근을 허용한 웹페이지에 번역 기능 주입
- tabs: 로그인 전용 탭과 현재 대상 탭 확인
- alarms: 로그인 시간 초과 및 콜백 누락 확인
- webNavigation: 접근 가능한 프레임 열거, 문서 이동에 따른 요청 무효화, 지정된 로그인 콜백 감지
- auth.openai.com·chatgpt.com: 인증·모델 조회·구독 번역
- api.openai.com: OpenAI API 키 검증·모델 조회·번역
- api.anthropic.com: Claude API 키 검증·모델 조회·번역
- sidePanel: 개발자 로그를 브라우저 사이드 패널에 표시
- 선택한 웹사이트 접근: 해당 사이트에서 번역과 단축키 사용

분석 SDK, 광고, 원격 실행 코드, 개발자 운영 프록시는 포함하지 않습니다.

전체 보관·삭제·수신자·문의 안내는 [영문 개인정보 설명](../PRIVACY.md)을 참고하세요. 갱신일: 2026-10-19.

## 브라우저 내장 AI

온디바이스 AI 모드는 호환되는 브라우저의 Prompt API를 사용하며 확장 프로그램에 API 키를 입력할 필요가 없습니다. 선택한 원문, 대상 언어, 활성화된 지시사항을 전용 확장 탭에서 브라우저 모델로 전달합니다. 확장 프로그램은 이 요청을 자체 OpenAI·Anthropic API 연결로 전송하거나 자동 전환하지 않습니다.

API 사용 가능 상태만으로 처리 위치를 확인할 수는 없습니다. 브라우저는 Prompt API를 기기 내 모델 또는 브라우저가 관리하는 클라우드 서비스로 구현할 수 있습니다. 실제 처리 위치, 브라우저가 수행하는 데이터 전송, 모델 다운로드에는 해당 브라우저의 설정과 개인정보처리방침이 적용됩니다. 확장 프로그램이 이 API를 통해 로컬 실행만을 보장할 수는 없습니다.

지원 여부를 확인할 때는 모델을 생성하거나 다운로드하지 않습니다. 사용자가 로컬 모델 준비 버튼을 누르면 모델 준비를 시작합니다. 숨겨진 실행 문서에서 준비가 확인되면 준비 탭을 닫아도 번역을 계속합니다. 명시적으로 중지하거나 연결 해제하면 작업을 취소합니다. 백그라운드 실행을 사용할 수 없을 때는 안내된 탭을 열어 두어야 합니다. 모델 파일은 브라우저가 관리하며 연결 해제로 삭제되지는 않습니다. 원문과 번역 캐시 및 개발자 로그에는 기존 보관·삭제 규칙이 적용됩니다. tabs 권한은 준비 탭을 열거나 찾는 데에도 사용합니다. offscreen 권한은 브라우저 AI를 실행하는 확장 내부 iframe을 호스팅하고 제어하는 데 사용합니다. 준비 상태 식별자와 필요한 언어 옵션만 신뢰된 로컬 저장소에 보관하며 페이지 텍스트는 이 기록에 저장하지 않습니다. 연결 해제 시 해당 준비 기록을 삭제합니다.

## 브라우저 Translator API

Translator API는 Prompt API와 별개의 선택적 연결입니다. 원문, 선택한 원본 언어·자동으로 판단한 언어 또는 페이지에 선언된 언어, 대상 언어를 전용 확장 탭의 브라우저 번역 엔진에 전달합니다. 사용자 지시문과 클라우드 인증 정보는 이 엔진에 전달하지 않습니다. 언어 팩 다운로드와 처리 위치는 브라우저가 관리하며, API 지원만으로 기기 내 처리를 보장하지 않습니다. 확장 프로그램의 OpenAI·Anthropic 연결로 자동 전환하지 않습니다.

다운로드가 필요한 언어 팩은 사용자가 준비 버튼을 클릭할 때 생성합니다. 번역 세션은 중지 또는 연결 해제 시 해제합니다. 백그라운드 실행 확인 후에는 준비 탭을 닫아도 동작하며, 탭 방식으로만 실행할 수 있는 브라우저에서는 탭을 닫으면 세션이 해제됩니다. 브라우저가 내려받은 언어 팩의 보존은 브라우저 설정을 따릅니다. 원문 복원, 페이지 메모리 캐시, 선택적 개발자 로그에는 기존 보존 정책이 적용됩니다. 두 브라우저 AI 모드는 위에서 설명한 offscreen 실행 문서와 권한을 공유합니다.

## 페이지 원본 언어와 언어 팩 목록

사이트 접근이 허용되고 Translator API가 지원되는 환경에서는 브라우저의 페이지 언어 감지 기능으로 팝업의 원본 언어를 제안합니다. 감지할 수 없으면 자동을 선택하며, 이 제안을 위해 클라우드 번역 요청을 보내지 않습니다. 현재 탭의 언어 선택·URL·문서 식별자는 trusted-context session 저장소에만 보관하고 새로고침·이동·탭 종료 시 지웁니다. 브라우저 재시작 뒤 유지하거나 설정으로 내보내지 않습니다.

준비한 Translator 언어 쌍과 최근 준비 요청의 언어 쌍은 페이지 내용이나 URL 없이 local 저장소에 기록합니다. 목록에서 제거해도 브라우저가 보관하는 언어 팩 파일은 삭제되지 않습니다. 브라우저 API가 전체 설치 목록 조회나 파일 삭제 기능을 제공하지 않기 때문입니다. 언어 쌍 기록은 인증 정보와 별개이며 연결 해제 뒤에도 남을 수 있습니다.
